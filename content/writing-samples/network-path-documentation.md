## Overview

Network Path provides visibility into the network routes and connectivity between systems, helping customers investigate network performance and troubleshoot connectivity issues.

I led and authored the Network Path documentation efforts across two Datadog product areas: Synthetics and Network Monitoring. This initiative involved translating complex networking concepts into accessible technical guidance, coordinating across product teams, and supporting a major feature launch.

Beyond the initial release, I used customer behavior analytics to evaluate documentation engagement, identify friction, and implement targeted content improvements.

## The Challenge

Network Path introduced technical concepts and workflows that needed to be documented for customers using different Datadog products.

The challenge was to develop clear, consistent documentation across Synthetics and Network Monitoring while addressing the distinct needs of each audience.

It was also important to evaluate how customers interacted with the documentation after launch, rather than relying solely on publication as a measure of success.

## My Role & Contributions

- **Led cross-product documentation efforts:** Owned and coordinated the documentation initiatives for Network Path across Synthetics and Network Monitoring.
- **Authored technical documentation:** Developed customer-facing content explaining Network Path capabilities, concepts, and workflows for both products.
- **Collaborated across teams:** Worked with Engineering and Product stakeholders to validate technical accuracy, align content with product functionality, and coordinate delivery.
- **Supported the product launch:** Organized documentation deliverables to support the release of Network Path.
- **Evaluated documentation performance:** Created a Product Analytics dashboard to track documentation traffic, engagement trends, and referral sources.
- **Identified and addressed customer friction:** Used Real User Monitoring (RUM), frustration signals, and heatmaps to investigate how customers interacted with the Synthetics documentation and identify opportunities for improvement.

## Measuring and Improving Documentation Engagement

Following the launch, I created a Product Analytics dashboard to establish a baseline for documentation traffic and monitor customer engagement with the Synthetics Network Path page.

I also used RUM, frustration signals, and heatmaps to investigate where customers encountered friction or dropped off the page.

Based on these findings, I restructured the documentation to include an [**Understanding Network Path Tests**](https://docs.datadoghq.com/synthetics/network_path_tests/#understanding-network-path-tests) section, providing additional context to help customers interpret and work with Network Path test results.

After publishing the changes, I revisited the analytics and observed a substantial improvement in frustration signals. Heatmaps also indicated that readers were spending time engaging with the newly added section.

This iterative process helped connect customer behavior with actionable documentation improvements.

## Sharing Insights with Engineering

I presented the Product Analytics report and my findings at a Synthetics Engineering summit, demonstrating how documentation analytics and RUM could be used to identify customer friction and guide content improvements.

The presentation highlighted the value of looking beyond page views to understand how customers navigate and engage with technical documentation.

## Outcome

Successfully led and authored Network Path documentation across Synthetics and Network Monitoring, delivering technical guidance for a complex capability spanning multiple products.

After launch, I used behavioral analytics to identify documentation friction, implemented targeted improvements, and observed improved frustration signals and reader engagement.

This project demonstrates my approach to documentation ownership throughout the full content lifecycle, from technical investigation and cross-functional collaboration to publication, measurement, and continuous improvement.
